# Bibliothèques et modèles de composants

Ce dossier contient des symboles, empreintes et modèles utilisés par le projet KiCad. Il comprend notamment des ressources pour les composants 2N2222A, IRF540N et IRF9540N ainsi qu’une bibliothèque Arduino.

Les chemins des bibliothèques doivent être configurés dans KiCad si elles ne sont pas trouvées automatiquement.
