# Fichiers du projet KiCad

Ce dossier contient le projet KiCad `tfc_Bosolindo` : configuration du projet (`.kicad_pro`), schéma (`.kicad_sch`) et circuit imprimé (`.kicad_pcb`). Ouvrez le fichier de projet avec KiCad pour accéder à la conception complète.

Les fichiers auxiliaires d’état de l’éditeur peuvent être générés localement par KiCad.
