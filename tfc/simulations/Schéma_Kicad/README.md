# Schéma KiCad

Ce dossier contient le projet de conception électronique KiCad du TFC. Le sous-dossier [`tfc_Bosolindo/`](tfc_Bosolindo/) regroupe le projet de carte, son schéma et les bibliothèques/symboles complémentaires.

Les fichiers `.kicad_pro`, `.kicad_sch` et `.kicad_pcb` sont des fichiers de projet, de schéma et de circuit imprimé KiCad.
