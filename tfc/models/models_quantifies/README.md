# Modèles TensorFlow Lite quantifiés

Ce dossier contient les modèles TensorFlow Lite quantifiés, notamment `commande_moteur_quantized_CNN1.tflite`. La quantification vise à réduire la taille et le coût d’inférence pour les appareils à ressources limitées.

Vérifiez la compatibilité des types et paramètres d’entrée avec le code de déploiement avant d’utiliser un modèle.
