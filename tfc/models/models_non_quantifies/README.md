# Modèles TensorFlow Lite non quantifiés

Ce dossier contient les modèles TensorFlow Lite exportés sans quantification, par exemple `commande_moteur_CNN1.tflite`.

Ces fichiers sont destinés à l’inférence avec un interpréteur TensorFlow Lite compatible. Le modèle utilisé par le programme embarqué est intégré séparément dans `moteur_voice/model.h`.
